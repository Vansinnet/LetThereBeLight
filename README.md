# LetThereBeLight

A Darktide Mod Framework mod for adjusting mission environments, including darkness, atmospheric lighting, Dawn, Inferno, and Ventilation Purge fog.

## Installation

Install DMF, place the `LetThereBeLight` folder in Darktide's mods directory, and add `LetThereBeLight` to `mod_load_order.txt`.
